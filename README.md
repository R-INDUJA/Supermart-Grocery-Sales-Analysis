# Supermart Grocery Sales Analysis & Dashboard

## Project Overview

This project analyzes a grocery sales dataset using Microsoft Excel to identify sales, profit, regional, category, and time-based performance trends.

The project demonstrates practical Excel skills used for entry-level Data Analyst, MIS, and Reporting roles, including data validation, data organization, formulas, PivotTables, PivotCharts, and dashboard reporting.

## Objectives

- Analyze overall sales and profit performance
- Compare sales and profit across regions
- Identify high- and low-performing product categories
- Analyze sub-category performance
- Identify monthly sales trends
- Build a dashboard to present key business metrics and insights

## Dataset

The project uses a Supermart Grocery Sales retail dataset containing approximately 10,000 sales records.

The dataset includes fields related to:

- Order information
- Customer information
- Product categories and sub-categories
- Location and region
- Order dates
- Sales
- Discounts
- Profit

## Tools & Skills

- Microsoft Excel

## Analysis Performed

### Data Validation

Checked the dataset for:

- Duplicate Order IDs
- Blank values
- Numeric ranges
- Category and region consistency
- Basic sales, discount, and profit statistics

The dataset contained 9,994 sales records, with unique Order IDs and no blank values in the checked fields.

### Time-Based Analysis

Created monthly sales and profit summaries from 2015 to 2018 using a date-based helper column and PivotTable analysis.

The analysis showed an overall increase in sales over the period, with several higher-performing months toward the later part of each year.

### Regional Analysis

Compared total sales, profit, and order volume across the five regions:

- Central
- East
- North
- South
- West

West recorded the highest overall sales and profit in the analysis.

### Category Analysis

Compared sales and profit across seven product categories to identify the strongest-performing product groups.

### Sub-Category Analysis

Analyzed 23 product sub-categories and identified the highest-performing sub-categories by sales and profit.

## Dashboard

The final Excel dashboard presents:

- Total Sales
- Total Profit
- Total Orders
- Average Sales per Order
- Monthly Sales Trend
- Regional Sales & Profit
- Category Sales & Profit
- Top 5 Sub-Categories by Sales

## Key Findings

- Total Sales: 14,956,982
- Total Profit: 3,747,121.20
- Total Orders: 9,994
- Average Sales per Order: approximately 1,496.49
- West was the highest-performing region by both sales and profit.
- September 2018 recorded the highest monthly sales at 705,680.
- Sales generally increased across the 2015–2018 period.
